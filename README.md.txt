# Smile Mask

**Smile Mask** – horror puzzle game with 15 levels.

## Controls
- WASD
- F9 / F11 – fullscreen

## Install
1. Install Python 3.12+
2. Install Pygame: `pip install pygame`
3. Run: `python main.py`

## Build .exe

pip install pyinstaller
pyinstaller --onefile --noconsole --icon=icon.ico main.py


## Warning
Contains bright flashes. Not recommended for people with epilepsy.
